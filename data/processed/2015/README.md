# Statistical Year Book of Maldives 2015 — Clean Datasets

This directory contains clean, machine-readable CSV datasets and structured JSON metadata converted from the official Statistical Yearbook of Maldives 2015 published by the National Bureau of Statistics (NBS).

## Dataset Overview
- **Total Chapters**: 17
- **Total Tables / CSV Files**: 207
- **Encoding**: UTF-8
- **Format**: Clean Tabular Matrix (English headers, pure numeric/category data rows, chart clutter and empty spacer columns stripped)
- **Metadata**: Companion `.json` for each table capturing Table ID, English Title, Dhivehi Title, Units, Source citations, and Footnotes.
